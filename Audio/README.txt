All sound in this folder is generated by  tools/make_audio.py  (numpy + scipy, no samples, no licences).

  music_calm.wav    garden theme, loops (C major, 92 BPM, 16 bars)
  music_tense.wav   chase stem, same tempo / length - cross-faded in by the game when teddies notice you
  ambience.wav      wind, water and birds, loops
  sfx_*.wav         gameplay + UI sounds (see SFX_NAMES in Autoloads/Sound.gd)

Re-generate after tweaking the script:   python3 tools/make_audio.py
To use your own audio, just overwrite a file with the same name (WAV or import an OGG and
change the extension in Autoloads/Sound.gd). Music files loop automatically.
